# チャンネル固定条件

台本を書く前にここを読む。ここを外すと作り直しになる。

## 出力仕様

| 項目 | 値 |
|---|---|
| 尺 | **60〜65秒**（TikTokの収益条件が1分以上。下限は動かせず、長いほどテンポが落ちる） |
| ナレーション | **四国めたん 単一**（掛け合いなし） |
| 投稿先 | YouTubeショート + TikTok の両方に同一素材 |
| 映像 | アニメ本編クリップが主。足りない分はAI生成画像で補う |
| 字幕 | 全編に載る前提。1行が折り返さない長さで書く |

## 視聴者と、題材の選び方

**アニメ勢がメイン。ただしアニメで描かれた内容そのものは伸びない。**

この2つは矛盾しない。狙うべきは両者の差分 — **アニメを見た人が、まだ知らない原作の先**。既に見た場面を解説されても新しい情報がないので離脱する。逆に「あのキャラのその後」は、知っている前提が効いたうえで未知が乗るので強い。

題材選定の原則:

- **アニメ範囲内で完結する話は避ける。** そのキャラの見せ場がアニメで描き切られているなら、その角度は捨てる
- **アニメで顔を知っているキャラ × 原作限定のその後** が最も強い。導入の説明が要らず、中身は全部новで新しい
- 原作限定の設定を出すときは「原作24巻」「蛇足編」のように出典を添える。知らない側を疎外せず、同時に「まだ読んでいない先がある」と伝わる
- アニメの放送状況は変わる。題材を決める前に**今どこまで放送されたかを毎回調べ直す**こと。前提が古いと、アニメ済みの内容を「原作限定」として出してしまう

## 表現の線引き

**性的な内容は明言しない。** 匂わせて止める。

これは規制回避であると同時に演出でもある。「情けない事情」「ある事情」でぼかした方が、視聴者が自分で補完してコメントが伸びる。断定した瞬間に、想像の余地とコメントの動機が同時に消える。

## 扱う作品

葬送のフリーレン / 転生したらスライムだった件 / 無職転生 / SPY×FAMILY

作品は1クールずつ20本単位で回している。

## 投稿管理表

```
1HYtHog63UKmJwC8eX97WGi72jS3SP5O-XjYFMrWoU_s
```

Google Driveの `read_file_content` で読む。列は `タイトル / URL / 番号 / 投稿予定日 / 投稿したか`。

各行のURLは、その回が属する20本セットの台本スプレッドシートを指している。書き上げた台本はそのシートに入れ、管理表のタイトル欄を埋める。

**投稿済みタイトルの一覧＝ネタ被りのブラックリスト。** 題材を決める前に必ず通す。

## 台本スプレッドシートの形式

1行1セリフの2列。

```
四国めたん,7年間、
四国めたん,好きな人のすぐ隣にいて、
```

左列が話者名、右列が読み上げテキスト。改行は行を分けることで表現する。

## 納品後の反映

台本が採用されたら、次の2つを更新する。

1. 該当する20本セットの台本スプレッドシートに、`四国めたん,テキスト` 形式で貼る
2. 投稿管理表のタイトル欄を埋める（該当する番号・投稿予定日の行）

**ただし、ユーザーが明示的に指示するまで書き込まない。** ここは本番の制作データで、台本が確定していない段階で書くと手戻りになる。台本を出したら「書き込みますか」と確認して、返事を待つ。

実際、台本を提示した時点では「まだ埋めないでください」と保留されることが多い。原作の事実確認や、尺の実測が済んでいないうちは確定できないため。
