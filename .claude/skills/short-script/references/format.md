# 「謎 → 回収 → 未完了」型

伸びているアニメ解説ショートから抽出した骨格。

冒頭で謎を立て、終盤で回収し、最後は投げる。以下の8ブロック名がこの型の正式な呼称で、他の呼び方はしない。

## 冒頭は2つの型を使い分ける

動画の中身によって、冒頭の入り方を変える。ここを取り違えると、どちらの型でも滑る。

| 台本の種類 | 冒頭 | 理由 |
|---|---|---|
| **エピソード型**（1つの出来事を語る） | **「とある日」直入り。タイトルコールなし** | 事件そのものが冒頭になる。何の話かは場面を見れば分かるので、宣言は要らない |
| **列挙型**（〇〇3選／ランキング／もしも〇〇なら） | **タイトルコールを置く** | 何を数えるのかを先に言わないと、視聴者は自分が何を見せられているか掴めない。列挙は枠組みが先に要る |

判定は単純で、**数を数えるなら列挙型**、1つの出来事を追うならエピソード型。

エピソード型で「アニメでは描かれない」「原作24巻」のような情報を伝えたいときは、**テロップに回す**。音声から抜いた以上、画面で見せないと「既に見た話」と誤解される。

## 尺配分（65秒想定）

### エピソード型

| 秒 | ブロック | 役割 | 書き方 |
|---|---|---|---|
| 0–7 | **とある日＋事件** | いきなり場面へ | 「とある日。」から入る。最後に「〜のはずだった」を置くと転換の予告になる |
| 7–15 | **引き（謎の提示）** | 続きを見る理由を作る | 最初のセリフをここまでに出す。予想外の反応を先出しして「なぜ？」を残す |
| 15–25 | 背景の最小説明 | ここで初めて説明 | 謎を成立させるのに必要な分だけ。ここまで説明を遅らせるのが要点 |
| 25–37 | 理由の提示 | 半分だけ明かす | 表向きの理由。まだ本命は伏せる |
| 37–48 | **2段目＝本命** | 「そういうことか」 | 動画の核。ここに一番いいセリフを置く |
| 48–59 | 回収 | 納得させる | 冒頭の謎に接続。伏線として閉じる |
| 59–65 | **未完了エンド** | コメント＋回遊 | 「それを知るのは、もう少し後の話」 |

### 列挙型

| 秒 | ブロック | 役割 |
|---|---|---|
| 0–4 | **タイトルコール** | 「〇〇3選」「もしも〇〇だったら」で枠組みを宣言 |
| 4–9 | 1本目の導入 | すぐ1つ目へ。前置きを挟まない |
| 9–： | 各項目 | 1項目あたり15〜18秒。最後の項目に一番強いものを置く |
| 〜65 | **未完了エンド** | 同上 |

どちらの型でも、**冒頭の15秒と未完了エンドは動かさない**。中間の配分は題材に合わせて動かしてよい。

## 冒頭5秒の設計（最重要）

ショートの成否はここでほぼ決まる。伸びている動画の冒頭を分解すると、共通しているのは次の4点。

**1. メタ情報を言わない。** 「無職転生、原作24巻」「アニメではまだ描かれていない話」のような、作品名・巻数・出典の宣言を音声で言うと、それだけで2秒が消える。視聴者にとって何の得もない秒数。**巻数や出典はテロップに回す。**

**2. 型に合った入り方をする。** 列挙型ならタイトルコールで枠組みを宣言する（視聴者は0.5秒で見るかどうかを判定しており、判定材料がないと切られる）。エピソード型なら「とある日」で場面に直入りする。上の「冒頭は2つの型を使い分ける」を参照。

**3. 状況説明から入らない。** 前置きを置かず、いきなり事件から始める。説明は謎を成立させるのに必要になった時点で、後から差し込む。

**4. セリフを10秒以内に出す。** これが決定的。地の文だけが続くとBGMのように流されるが、人の声で「」が入ると耳が止まる。**最初のセリフが30秒地点にあるような台本は、冒頭が死んでいる。**

### やってしまいがちな悪い冒頭

```
アニメ1期で、あの緑髪の戦士に救われた子供は、   ← 否定形で絵が浮かばない
ルーデウスだけじゃない。
無職転生、原作24巻。                          ← メタ情報
アニメではまだ描かれていない話。                 ← さらにメタ情報
```

事件が何も始まっておらず、最初のセリフは32秒後。

### 直したもの

```
とある日。                                    ← 直入り
ノルンのもとに、知らせが届く。

「スペルド族の村に疫病。ルイジェルドが危ない」    ← 7秒でセリフ

……なのに、こう答えた。

「私は、ここに残ります」                        ← 13秒で予想外＝謎
```

（エピソード型なので、タイトルコールは置かない。「原作24巻・アニメ未放送」はテロップへ）

物語の中盤にある一番意外な反応を**冒頭に前倒しして、理由を伏せる**。これが「続きが気になる冒頭」の作り方。時系列どおりに並べる必要はない。

## なぜこの順番なのか

- **タイトルコールを先に置く理由** — 視聴者は0.5秒で「見るかどうか」を判定している。判定材料がないと切られる。矛盾や意外性を1行で宣言すると、解消を見たくなる。
- **人物名は出してよい** — アニメで顔を知っているキャラなら、名前そのものが視聴理由になる。「あの人の話か」で止まる。伏せるのは**人物ではなく理由**。誰の話かは明かし、なぜそうなったかを伏せる。
- **謎を冒頭に前倒しする理由** — 時系列どおりに並べると冒頭が説明で埋まる。物語の中盤にある一番意外な反応を先に出し、理由だけ伏せると、それがそのまま「続きを見る理由」になる。
- **説明を16秒まで遅らせる理由** — 背景から入ると、謎が立つ前に離脱される。説明は謎を成立させるのに必要になった時点で初めて差し込む。
- **本命を1つ置く理由** — 山が複数あると散る。42〜58秒に一番いいセリフを1つ置き、そこに向けて全部を積む。
- **回収する理由** — 冒頭の謎が終盤で解けると、視聴者は「ちゃんと着地した」と感じる。開きっぱなしのフックは信用を削る。
- **終わらせない理由** — 未完了は「気になる」を残す。コメントと次動画への回遊が同時に立つ。最大の離脱点はオチた瞬間なので、そこで完結させない。

## 変数の置き換え

| ブロック | 作り方 |
|---|---|
| タイトルコール | 「アニメでは描かれない、〇〇の話」。人物を名指しし、何の動画かを1行で宣言する |
| 事件 | 一目で分かる場面をひとつ。長い経緯が要る場面は選ばない |
| 引き（謎） | 予想される反応を書いてから外す。外した理由は伏せる |
| 2段目＝本命 | 伏せていた理由を明かす。感情の底（コンプレックス・過去）に触れると強い |
| 未完了 | 「それを知るのは、もう少し後の話」／「〜かどうかは、また別の話」 |

## 文体ルール

- **1文 15〜25文字。** 音声で聞き取れる長さで、字幕が1行に収まる長さ。
- **1行1文。** 改行を多く取る。字幕とVOICEVOXの区切りが揃う。
- **地の文と会話を交互に。** 同じ調子が続くと聞き流される。
- **短文を混ぜる。** 「逆だった。」「護衛。」のような3〜5文字の行がリズムを作る。
- **体言止めを混ぜる。** 「〜です」「〜ます」が続いたら切る。
- **結論を先に言わない。** 「〜だったんです」を中盤で出すと、そこで離脱する。

## 尺の計算

四国めたん（VOICEVOX 標準速度）でおおむね **6〜6.5文字/秒**。句読点の間を含む。

```
必要文字数 = 目標秒数 × 6.2
```

**目標は390〜410文字（約63〜66秒）。** TikTokの収益条件が1分以上なので下限は動かせず、一方で長いほどテンポは落ちるため、60秒をわずかに超えるところを狙う。

### 係数がずれたときの事故

400文字前後は余裕が薄い。話速が想定より速いと収益条件を割る。

| 話速 | 400文字の実尺 |
|---|---|
| 6.0文字/秒 | 67秒 |
| 6.2文字/秒 | 65秒 |
| 6.5文字/秒 | 62秒 |
| 7.0文字/秒 | **57秒 — 条件を割る** |

**一度書き出して実尺を測る。** そのうえで「文字数 ÷ 実尺」から係数を出し直せば、以降は計算で足りる。

台本を渡すときは、**60秒を割った場合に足せる「保険行」を2つ添える**とよい。1行15文字前後で、意味を壊さない位置（背景説明の末尾、感情の描写）に置けるものを選ぶ。後から足すより、最初から用意しておくほうが早い。

## 削るときにどこから削るか

長すぎるとき、まず疑うのは**後半での言い直し**。前半で描写した行動を後半でもう一度説明していることが多い。実際に80秒→65秒へ圧縮したときも、最大の削減は回収ブロックの重複描写だった。

次に落とすのは**地名・数値などの固有情報**。情報としては重いが、感情には効かない。「ミリスからシャリーアまで連れてきた」は「連れてきた」で足りる。

逆に削ってはいけないのは、冒頭5秒、セリフ、そして未完了エンド。ここを削ると尺は縮むが動画が死ぬ。

## タイトル

2行構成。矛盾か意外性を1行目に置く。

```
アニメでは絶対に描かれない
ルイジェルドが死にかけた日の話
```

**核心のセリフはタイトルに使わない。** 動画の山（2段目＝本命）を先に潰してしまう。タイトルで見せるのは謎の入口だけにする。

「〜がヤバい…」「〜3選」は既に大量にあるので、語尾が被らないようにする。埋もれる。
