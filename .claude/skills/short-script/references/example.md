# 完成例：シルフィエット（無職転生）

型がどう埋まるかの実例。約446文字＝約69秒。

## タイトル

```
7年間ずっと隣にいたのに
気づいてもらえなかった女の子
```

## 台本

```
【0-4秒／異常ラベル】
7年間、
好きな人のすぐ隣にいて、
一度も名乗らなかった人物がいる。

【4-9秒／最小状況】
無職転生。
シルフィエット。

【9-20秒／視覚的事件】
魔法大学。
ルーデウスの前に、
フィッツという名の護衛が現れる。

サングラス。
男物の制服。
声も、話し方も、別人。

ルーデウスは、気づかない。

【20-32秒／1段目のズレ】
普通なら、名乗る。

幼馴染だ。
助けてもらった相手だ。
魔術を教わった相手だ。

でも彼女は、
最後まで黙っていた。

【32-46秒／2段目＝本命】
理由は、
覚えていてもらえなかったからじゃない。

逆だった。

7年前と、
髪の色が変わっていた。

自分が、
あの頃の自分じゃなくなっていた。

「気づかれなかったら」じゃない。

「気づかれて、がっかりされたら」が怖かった。

【46-58秒／ラベル回収】
だから彼女は、
名乗る代わりに「先輩」になった。

隣に立てて、
顔を隠せて、
名乗らなくていい距離。

7年分の想いを、
サングラス1枚の内側に置いたまま。

【58-70秒／第2エピソード】
そしてルーデウスは、
この護衛を長いあいだ、
男だと思っている。

友達だと思っている。

一番会いたかった相手が、
毎日となりにいるのに。

【70-78秒／未完了エンド】
ちなみに、
この関係が動き出すきっかけは、
ルーデウス側の、
とんでもなく情けない事情だった。

それを知るのは、
もう少しだけ後の話。
```

## なぜこの題材か

投稿管理表の無職転生37本を確認したところ、**シルフィエット単独の回が1本もなかった**。妻3人をまとめた回はあるが、彼女個人の感情を扱った回はない。アニメ2期で描かれた範囲なので、アニメ勢が置いていかれない点も条件に合う。

## 型との対応

| ブロック | この台本での実装 |
|---|---|
| 異常ラベル | 「7年間、名乗らなかった」— 矛盾で疑問を立て、名前は伏せる |
| 視覚的事件 | サングラス＋男装＋気づかないルディ。音を切っても成立する |
| 1段目のズレ | 「普通なら、名乗る」と期待を明示してから外す |
| 2段目＝本命 | 理由の反転（忘れられたからではなく、変わった自分を見られたくない） |
| ラベル回収 | 「サングラス1枚の内側」で冒頭の7年に接続 |
| 第2エピソード | ルディ側の視点に切り替え、すれ違いの絵で締める |
| 未完了 | きっかけを「情けない事情」でぼかす。明言しない条件にも合致 |

## 表現の判断

きっかけとなる出来事は明言せず「情けない事情」で止めている。ぼかした方が、知っている層は察してコメントし、知らない層は調べたくなる。断定するとその両方が消える。

## 事実確認が要る箇所

- **名乗らなかった理由** — 原作には複数の要因（容姿の変化、立場、ルディ側の状況）がある。この台本は「容姿の変化への不安」に絞っており、**解釈が入っている**。ここは書き手が原作を確認して調整する前提。
- 髪の色の変化が転移時の魔力によるものである点、フィッツとして護衛に就いていた点は原作記述どおり。
