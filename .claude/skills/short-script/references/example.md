# 完成例：ノルンとルイジェルド（無職転生・原作24巻）

型がどう埋まるかの実例。約402文字＝約65秒。**原作EPUBで全事実を確認済み。**

## 題材の選定過程

| 案 | 結果 |
|---|---|
| ロキシー（崇拝されている自覚がない） | ✗ 投稿管理表に「ロキシー教の真の理由」が既出 |
| シルフィエット（7年間正体を隠した） | ✗ アニメ2期で描き切られている |
| エリス（空白の5年間） | ✗ アニメ3期の1〜2話で放送済み |
| **ノルンとルイジェルド（24巻の間話）** | ✓ 原作限定・未使用・アニメ勢が両者の顔を知っている |

**アニメで顔を知っているキャラ × 原作限定のその後**が最も強い。3期は13巻からなので24巻には当分届かない。

## タイトル

```
あの緑髪の戦士に救われたのは
ルーデウスだけじゃなかった
```

核心のセリフはタイトルに使わない。46〜60秒の山を先に潰してしまうため。

## 台本

冒頭は初稿から作り直している。初稿は「アニメ1期で、あの緑髪の戦士に救われた子供は、ルーデウスだけじゃない。無職転生、原作24巻。アニメではまだ描かれていない話。」で始めていた。メタ情報に2秒、最初のセリフは32秒地点。冒頭が死んでいた。

物語の中盤にある一番意外な反応（「私は、ここに残ります」）を**15秒地点に前倒しし、理由を伏せる**構成に変えてある。

```
【0-4秒／タイトルコール】
アニメでは絶対に描かれない、
ルイジェルドが死にかけた日の話。


【4-9秒／とある日＋事件】
とある日。
ノルンに、知らせが届く。

「スペルド族の村に疫病。
ルイジェルドが危ない」


【9-16秒／引き＝謎の提示】
ルーデウスの妹、ノルン。

彼女にとっても、恩人だった。

なのに、こう答えた。

「私は、ここに残ります」


【16-24秒／恩の中身】
幼い頃。

父と離ればなれになって、
泣いてばかりだった彼女を、

膝に乗せて、
昔話で泣き止ませた人。


【24-37秒／残る理由】
その恩人が、死にかけている。

それでも彼女は動かなかった。

家に、幼い姪がいたから。

ルーシー。

いつも寂しそうにしている子。

自分まで出ていけば、また一人になる。


【37-49秒／2段目＝本命】
ところが。

そのルーシーが、
ノルンの手を引いた。

小さな手で、立たせながら、
こう言った。

「ノルンお姉ちゃんは、
ルイジェルドさんなの」


【49-59秒／回収】
ルイジェルドがノルンにしたことを、
ノルンはルーシーにしていた。

気づいていないのは、本人だけ。

タイトルは、
「誰かにとっての誰か」。


【59-65秒／未完了エンド】
ノルンが村に着いたとき、
ルイジェルドが生きていたかは、

また、別の話。
```

セリフの配置は8秒・15秒・47秒。「原作24巻」は音声では言わず、テロップに回す。

### 80秒版からの圧縮

最初は505文字・約80秒で書き、テンポを上げるため402文字・約65秒へ落とした。削り方の内訳:

| ブロック | 前 | 後 | 削ったもの |
|---|---|---|---|
| 恩の中身 | 83 | 46 | 「ミリスからシャリーアまで連れてきた」— 地名は情報として重いが感情には効かない |
| 残る理由 | 94 | 77 | 「親が家を空けがちで」— 「いつも寂しそう」だけで足りる |
| 回収 | 95 | 64 | 「寂しくて泣く子のそばにいて、話を聞いてやる」— 前半で描写済みの重複 |

最大の削減は**回収ブロックの重複**だった。ルイジェルドが何をしたかは16-24秒で見せてあるので、後半で言い直す必要がなかった。長すぎるときはまずここを疑う。

### 保険行

402文字は余裕が薄く、話速が想定より速いと60秒を割る。実尺を測って足りなければ、以下を足すと約5秒伸びる。

- 16-24秒ブロックの末尾に「泣いても、一度も怒らなかった。」（約2.4秒）
- 24-37秒ブロックの「自分まで出ていけば」の前に「行きたい。／でも、行けない。」（約2.6秒）

どちらも意味を壊さず、感情を足す方向に働く位置を選んである。

## 型との対応

| ブロック | 実装 |
|---|---|
| タイトルコール | 「アニメでは絶対に描かれない」で判定材料を与え、同時に人物と事件を名指しする |
| とある日＋事件 | 説明を挟まず場面へ。9秒でセリフが出る |
| 引き | 「残ります」を15秒に前倒し。理由を伏せて「なぜ？」だけ残す |
| 2段目＝本命 | 幼児が手を引いて放つ一言。動画の山 |
| 回収 | 伏せていた理由がここで意味に変わる。章タイトルが伏線として閉じる |
| 未完了 | 安否だけ伏せる。感情は着地させ、筋は開いたままにする |

感情の設計が二層になっている。表は「恩人を助けに行けるか」、裏は「優しさが次の世代へ渡っている」。表で引っ張り、裏で刺す。

## 原作確認で分かったこと（重要）

このスキルの初版の例は、まとめブログだけを根拠に書いていて**事実を2箇所間違えていた**。原作を読んで判明した。

| ブログ由来の記述 | 原作24巻の実際 |
|---|---|
| ルイジェルドは疫病で死亡する | **生還する。**「完治した後、俺はお前の力となろう」と告げ、ルーデウスの味方になる |
| ルーデウスが村を守り抜いた | 疫病を解いたのは**クリフ・グリモル**。ルーデウスは各国に救援を求めた側 |

しかも疫病の正体そのものが、単なる病ではなかった疑いが本文で示唆されている。

一次資料が手に入るなら必ずあたること。まとめ系サイトは互いにコピーし合っていて、キャラの生死のような根幹で誤情報が増殖している。

## 引用したセリフ（原文どおり）

- 「……いえ、私は、ここに残ります」
- 「ノルンお姉ちゃんは、ルイジェルドさんなの」

台本で直接引用するのはこの2つだけに絞っている。地の文はすべて書き下ろし。原作の文章をそのまま流すのではなく、事実を確認したうえで自分の言葉で構成する。
