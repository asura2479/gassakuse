# チャンネル固定条件

台本を書く前にここを読む。ここを外すと作り直しになる。

## 出力仕様

| 項目 | 値 |
|---|---|
| 尺 | **1分以上**（TikTokの収益条件。60秒を割ったら不合格） |
| ナレーション | **四国めたん 単一**（掛け合いなし） |
| 投稿先 | YouTubeショート + TikTok の両方に同一素材 |
| 映像 | アニメ本編クリップが主。足りない分はAI生成画像で補う |
| 字幕 | 全編に載る前提。1行が折り返さない長さで書く |

## 視聴者

**アニメ勢がメイン。** 原作未読でも置いていかれない書き方にする。

- 原作限定の設定を出すときは「原作では」と一言添えて、知らない側を疎外しない
- アニメ範囲外の展開は、ネタバレの重さを見て扱いを決める
- 逆に、アニメで描かれた場面は説明を削ってよい。知っている前提で走れる

## 表現の線引き

**性的な内容は明言しない。** 匂わせて止める。

これは規制回避であると同時に演出でもある。「情けない事情」「ある事情」でぼかした方が、視聴者が自分で補完してコメントが伸びる。断定した瞬間に、想像の余地とコメントの動機が同時に消える。

## 扱う作品

葬送のフリーレン / 転生したらスライムだった件 / 無職転生 / SPY×FAMILY

作品は1クールずつ20本単位で回している。

## 投稿管理表

```
1HYtHog63UKmJwC8eX97WGi72jS3SP5O-XjYFMrWoU_s
```

Google Driveの `read_file_content` で読む。列は `タイトル / URL / 番号 / 投稿予定日 / 投稿したか`。

各行のURLは、その回が属する20本セットの台本スプレッドシートを指している。書き上げた台本はそのシートに入れ、管理表のタイトル欄を埋める。

**投稿済みタイトルの一覧＝ネタ被りのブラックリスト。** 題材を決める前に必ず通す。

## 台本スプレッドシートの形式

1行1セリフの2列。

```
四国めたん,7年間、
四国めたん,好きな人のすぐ隣にいて、
```

左列が話者名、右列が読み上げテキスト。改行は行を分けることで表現する。
