# 競合ショートの構造分析チェックリスト

伸びている動画を分解するときの観点。文字起こしだけでも大半は取れる。

## 抽出してよいもの / いけないもの

| 抽出する | しない |
|---|---|
| ブロック構成と秒数配分 | セリフそのもの |
| テンポ（文の長さ、間の作り方） | 固有のキャッチフレーズ・署名的表現 |
| 感情の設計（どこで何を感じさせるか） | 題材・キャラの選択 |
| 引っ張り方（何を伏せ、いつ開くか） | ナレーションの言い回し |

同じ機能を**別の語彙で作り直す**のが基本。競合が「〇〇がバグってる」で矛盾を提示しているなら、こちらは「〇〇なのに〇〇だと思っている」で同じ機能を作る。構造は共有財産だが、表現は個人のもの。

## 分解の観点

**冒頭3秒**
- 何を提示している？（情報／矛盾／疑問／断定）
- 人物名を出しているか、伏せているか
- 何秒で最初の「引っかかり」が来るか

**状況説明**
- 何文字で済ませているか
- 何を説明せず捨てているか — ここが一番学べる

**事件の置き方**
- 音を切っても分かる場面か
- 説明が要る場面を避けているか

**ズレの構造**
- 視聴者の期待を明示しているか
- 何段外しているか
- 各段の間隔は何秒か

**視聴者の代弁者**
- 困惑や納得を代弁するキャラがいるか
- いない場合、地の文がその役をしているか

**フックの回収**
- 冒頭の宣言は回収されているか
- 何秒地点で回収しているか

**離脱点の処理**
- オチの直後に何を置いているか
- 尺の後半に別ネタを差しているか、その比率は

**終わり方**
- 完結しているか、投げているか
- 投げている場合、何を伏せたか

## 数値が取れる場合

再生数・視聴維持率グラフが見られるなら、推測より優先する。維持率の落ち込み位置と、上で分解したブロック境界を突き合わせると、どの設計が効いてどれが効いていないかが直接分かる。

維持率が取れない場合は、分解結果が仮説であることを明示する。断定しない。

## 出力形式

分解結果は「観察 → なぜ効くか」の順で書く。観察だけだと再利用できず、理屈だけだと検証できない。
