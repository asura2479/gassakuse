# 「ラベル → 証明 → 未完了」型

伸びているアニメ解説ショートから抽出した骨格。1分以上の尺を前提にした配分。

## 尺配分（70秒想定）

| 秒 | ブロック | 役割 | 書き方 |
|---|---|---|---|
| 0–4 | **異常ラベル** | 疑問を立てる | 断定形で矛盾か異常を提示。**人物名は出さない**。「誰の話だ？」を作る |
| 4–9 | 最小状況 | 着地させる | 作品名とキャラ名だけ。背景説明はしない |
| 9–20 | 視覚的事件 | 画で理解させる | 音を切っても分かる場面を1つ。ここが素材選定の軸になる |
| 20–32 | 1段目のズレ | 「ん？」 | 視聴者が予想する反応を書いてから、外す |
| 32–46 | **2段目＝本命** | 「そういうことか」 | もう一段外す。ここが動画の核 |
| 46–58 | ラベル回収 | 納得させる | 冒頭のラベルに接続。伏線として閉じる |
| 58–70 | 第2エピソード | 離脱を潰す | オチ直後の離脱点を塞ぐ。メインより短く |
| 70–78 | **未完了エンド** | コメント＋回遊 | 「それを知るのは、もう少し後の話」 |

冒頭3秒と未完了エンドは動かさない。中間の配分は題材に合わせて動かしてよい。

## なぜこの順番なのか

- **ラベルを先に置く理由** — ショートは「見る理由」が3秒以内に要る。情報を出しても理由にならないが、矛盾は理由になる。「強いのに弱いと思っている」のような矛盾は、解消を見たくさせる。
- **人物名を伏せる理由** — 名前を出すと「知らないキャラだ」で切られる。属性だけなら誰でも入れる。
- **ズレを2段にする理由** — 1段だと「へえ」で終わり、3段だと間延びする。2段目で回収されると笑いか納得が発生する。
- **ラベルを回収する理由** — 冒頭の宣言が中盤で証明されると、視聴者は「ちゃんと着地した」と感じる。言いっぱなしのフックは信用を削る。
- **オチの直後に第2話を置く理由** — 完走率が落ちるのはオチた瞬間。ここに次を被せると、視聴者は残りを消化する。
- **終わらせない理由** — 未完了は「気になる」を残す。コメントと次動画への回遊が同時に立つ。

## 変数の置き換え

| 変数 | 作り方 |
|---|---|
| ラベル | キャラの一言属性（自己評価／羞恥心／金銭感覚／危機感／執着 が壊れている） |
| 事件 | 一目で分かる場面をひとつ。長い経緯が要る場面は選ばない |
| 1段目のズレ | 「普通なら〜」と書いてから外す。予想を明示すると外れが効く |
| 2段目のズレ | 理由を明かす。ここで感情の底（コンプレックス・過去）に触れると強い |
| 未完了 | 「それを知るのは、もう少し後の話」／「〜が判明するのは別の話」 |

## 文体ルール

- **1文 15〜25文字。** 音声で聞き取れる長さで、字幕が1行に収まる長さ。
- **1行1文。** 改行を多く取る。字幕とVOICEVOXの区切りが揃う。
- **地の文と会話を交互に。** 同じ調子が続くと聞き流される。
- **短文を混ぜる。** 「逆だった。」「護衛。」のような3〜5文字の行がリズムを作る。
- **体言止めを混ぜる。** 「〜です」「〜ます」が続いたら切る。
- **結論を先に言わない。** 「〜だったんです」を中盤で出すと、そこで離脱する。

## 尺の計算

四国めたん（VOICEVOX 標準速度）でおおむね **6〜6.5文字/秒**。句読点の間を含む。

```
必要文字数 = 目標秒数 × 6.2
```

- 60秒ちょうど → 約370文字（**余裕がないので不可**）
- 70秒 → 約435文字
- 75秒 → 約465文字

**目標は430〜480文字。** 60秒を確実に超えるための下駄を履かせている。

話速の設定を変えている場合はこの係数がずれる。既存の台本1本を「文字数 ÷ 実尺」で割って係数を出し直すと正確になる。

尺が足りないときに伸ばすのは**第2エピソード**。冒頭や説明を膨らませるとテンポが死ぬ。

## タイトル

2行構成。矛盾を1行目に置く。

```
7年間ずっと隣にいたのに
気づいてもらえなかった女の子
```

「〜がヤバい…」「〜3選」は既に大量にあるので、語尾が被らないようにする。埋もれる。
