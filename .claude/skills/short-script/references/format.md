# 「ラベル → 証明 → 未完了」型

伸びているアニメ解説ショートから抽出した骨格。1分以上の尺を前提にした配分。

## 尺配分（70秒想定）

| 秒 | ブロック | 役割 | 書き方 |
|---|---|---|---|
| 0–4 | **タイトルコール** | 何の動画か即断させる | 「アニメでは描かれない、〇〇の話」「もしも〇〇だったら」「〇〇3選」 |
| 4–10 | **とある日＋事件** | 即座に場面へ | 「とある日。」から入って、すぐ事件を起こす |
| 10–16 | **引き（謎の提示）** | 続きを見る理由を作る | 最初のセリフをここまでに出す。予想外の反応を先出しして「なぜ？」を残す |
| 16–28 | 背景の最小説明 | ここで初めて説明 | 謎を成立させるのに必要な分だけ。ここまで説明を遅らせるのが要点 |
| 28–42 | 理由の提示 | 半分だけ明かす | 表向きの理由。まだ本命は伏せる |
| 42–58 | **2段目＝本命** | 「そういうことか」 | 動画の核。ここに一番いいセリフを置く |
| 58–72 | 回収 | 納得させる | 冒頭の謎に接続。伏線として閉じる |
| 72–80 | **未完了エンド** | コメント＋回遊 | 「それを知るのは、もう少し後の話」 |

0〜16秒と未完了エンドは動かさない。中間の配分は題材に合わせて動かしてよい。

## 冒頭5秒の設計（最重要）

ショートの成否はここでほぼ決まる。伸びている動画の冒頭を分解すると、共通しているのは次の4点。

**1. メタ情報を言わない。** 「無職転生、原作24巻」「アニメではまだ描かれていない話」のような、作品名・巻数・出典の宣言を音声で言うと、それだけで2秒が消える。視聴者にとって何の得もない秒数。**巻数や出典はテロップに回す。**

**2. タイトルコールを置く。** 「〇〇3選」「もしも〇〇と結婚していたら」のように、この動画が何かを1行で宣言する。視聴者は0.5秒で「見るかどうか」を判定していて、判定材料がないと切られる。シリーズ名として固定できるとさらに強い。

**3. 「とある日」で場面に直入りする。** 状況説明を先に置かず、いきなり事件から始める。説明は謎を成立させるのに必要になった時点で、後から差し込む。

**4. セリフを10秒以内に出す。** これが決定的。地の文だけが続くとBGMのように流されるが、人の声で「」が入ると耳が止まる。**最初のセリフが30秒地点にあるような台本は、冒頭が死んでいる。**

### やってしまいがちな悪い冒頭

```
アニメ1期で、あの緑髪の戦士に救われた子供は、   ← 否定形で絵が浮かばない
ルーデウスだけじゃない。
無職転生、原作24巻。                          ← メタ情報
アニメではまだ描かれていない話。                 ← さらにメタ情報
```

事件が何も始まっておらず、最初のセリフは32秒後。

### 直したもの

```
アニメでは絶対に描かれない、                    ← タイトルコール
ルイジェルドが死にかけた日の話。

とある日。                                    ← 直入り
ノルンのもとに、知らせが届く。

「スペルド族の村に疫病。ルイジェルドが危ない」    ← 9秒でセリフ

……なのに、こう答えた。

「私は、ここに残ります」                        ← 15秒で予想外＝謎
```

物語の中盤にある一番意外な反応を**冒頭に前倒しして、理由を伏せる**。これが「続きが気になる冒頭」の作り方。時系列どおりに並べる必要はない。

## なぜこの順番なのか

- **ラベルを先に置く理由** — ショートは「見る理由」が3秒以内に要る。情報を出しても理由にならないが、矛盾は理由になる。「強いのに弱いと思っている」のような矛盾は、解消を見たくさせる。
- **人物名を伏せる理由** — 名前を出すと「知らないキャラだ」で切られる。属性だけなら誰でも入れる。
- **ズレを2段にする理由** — 1段だと「へえ」で終わり、3段だと間延びする。2段目で回収されると笑いか納得が発生する。
- **ラベルを回収する理由** — 冒頭の宣言が中盤で証明されると、視聴者は「ちゃんと着地した」と感じる。言いっぱなしのフックは信用を削る。
- **オチの直後に第2話を置く理由** — 完走率が落ちるのはオチた瞬間。ここに次を被せると、視聴者は残りを消化する。
- **終わらせない理由** — 未完了は「気になる」を残す。コメントと次動画への回遊が同時に立つ。

## 変数の置き換え

| 変数 | 作り方 |
|---|---|
| ラベル | キャラの一言属性（自己評価／羞恥心／金銭感覚／危機感／執着 が壊れている） |
| 事件 | 一目で分かる場面をひとつ。長い経緯が要る場面は選ばない |
| 1段目のズレ | 「普通なら〜」と書いてから外す。予想を明示すると外れが効く |
| 2段目のズレ | 理由を明かす。ここで感情の底（コンプレックス・過去）に触れると強い |
| 未完了 | 「それを知るのは、もう少し後の話」／「〜が判明するのは別の話」 |

## 文体ルール

- **1文 15〜25文字。** 音声で聞き取れる長さで、字幕が1行に収まる長さ。
- **1行1文。** 改行を多く取る。字幕とVOICEVOXの区切りが揃う。
- **地の文と会話を交互に。** 同じ調子が続くと聞き流される。
- **短文を混ぜる。** 「逆だった。」「護衛。」のような3〜5文字の行がリズムを作る。
- **体言止めを混ぜる。** 「〜です」「〜ます」が続いたら切る。
- **結論を先に言わない。** 「〜だったんです」を中盤で出すと、そこで離脱する。

## 尺の計算

四国めたん（VOICEVOX 標準速度）でおおむね **6〜6.5文字/秒**。句読点の間を含む。

```
必要文字数 = 目標秒数 × 6.2
```

- 60秒ちょうど → 約370文字（**余裕がないので不可**）
- 70秒 → 約435文字
- 75秒 → 約465文字

**目標は430〜480文字。** 60秒を確実に超えるための下駄を履かせている。

話速の設定を変えている場合はこの係数がずれる。既存の台本1本を「文字数 ÷ 実尺」で割って係数を出し直すと正確になる。

尺が足りないときに伸ばすのは**第2エピソード**。冒頭や説明を膨らませるとテンポが死ぬ。

## タイトル

2行構成。矛盾を1行目に置く。

```
7年間ずっと隣にいたのに
気づいてもらえなかった女の子
```

「〜がヤバい…」「〜3選」は既に大量にあるので、語尾が被らないようにする。埋もれる。
