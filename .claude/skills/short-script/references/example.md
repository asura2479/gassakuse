# 完成例：ルイジェルド（無職転生）

型がどう埋まるかの実例。約438文字＝約71秒。

## 題材の選定過程

**没案1：ロキシー**（崇拝されている自覚がない）
→ 投稿管理表に「ロキシー教の真の理由」が既出。角度を変えても被り。

**没案2：シルフィエット**（7年間正体を隠した）
→ 未使用ネタで感情設計も強かったが、**アニメ2期で描き切られている**。アニメ範囲の内容は伸びない。

**採用：ルイジェルド**
- アニメ1期の人気キャラで、顔と目的をアニメ勢全員が知っている
- 別れて以降アニメには出ておらず、**その後は原作限定**（本編24〜25巻＋蛇足編）
- 3期は13巻からなので、当分アニメでは追いつかない
- 投稿管理表に未使用。ノルンも未使用

**アニメで顔を知っているキャラ × 原作限定のその後** が最も強い、という原則どおりの選び方。

## 型との対応

| ブロック | 実装 |
|---|---|
| 異常ラベル | 「アニメで別れた男の願いが、原作の最後で叶う」— 名前を出さず「緑髪の戦士」で特定させる |
| 目的の提示 | 名誉回復という願いを先に置く。これが最後まで引っ張る芯になる |
| 1段目のズレ | 「普通なら剣で」と予想を明示してから「人形だった」で外す |
| 2段目＝本命 | 手段の意味を開く（戦って認めさせるのではなく、次世代の常識を書き換える） |
| ラベル回収 | 24巻で願いが実際に叶う。冒頭の宣言を閉じる |
| 第2エピソード | 本編の外（蛇足編）へ。ノルンとの結婚で予想外を足す |
| 未完了 | 「最後の戦士」という語だけ置いて理由を伏せる |

## 出典を明示する理由

「原作24巻」「蛇足編」と作中で言っている。原作限定だと伝わることで、アニメ勢に「まだ先がある」と分からせられる。ネタバレ配慮であると同時に、次の動画への引きにもなる。

## 事実確認が要る箇所

裏取りの過程で、**まとめブログ間で記述が食い違った**。断定を避けた箇所と、確認が要る箇所は以下。

- **ルイジェルドの生死** — 「疫病で死亡」と書くブログと「生存」と書くブログがある。**台本では一切触れていない。** 触れるなら原作で確認してから。
- **「この縁談、進めてください」** — 二次情報からの引用。原作の実際の文言と異なる可能性があるので、確認するか、地の文に言い換える。
- **名誉回復と疫病の前後関係** — 台本は「人形を広める → 24巻で村の危機 → 守り抜いて国に認められる」の順で書いている。この順序は複数ソースで一致したが、巻数まで含めて確認しておくと安全。
